# VitalyaClicker — релизы

Исходники игры в этот репозиторий не выкладываются. Здесь лежит только то, что нужно игрокам:

- **Releases** — собранные обновления (VitalyaClicker.exe для Windows, VitalyaClicker.apk для Android). Игра сама проверяет новые версии и предлагает обновиться.
- **server.txt** — актуальный адрес игрового сервера (туннель cloudflared). Меняется каждые 6 часов, поэтому игра читает адрес отсюда.

## Запуск сервера

- Windows: `tools\run-server.cmd`
- Linux: `tools/run-server.sh`

Скрипт поднимает игровой сервер, туннель cloudflared, пишет адрес в `tools/server.txt` и публикует его здесь.

## Выпуск обновления

В игре: «Онлайн» → «Админ» → «🚀 Выпустить обновление» (доступно владельцу).

Или вручную: `node tools/release.js --version 1.0.1`
