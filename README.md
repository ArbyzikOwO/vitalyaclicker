# VitalyaClicker 69

Кликер-игра с онлайн-режимом: прокачка и скины, облачные сохранения, чат и друзья, переводы монет,
онлайн-банк, аркада (монетка, кости, рулетка), карточные столы (блэкджек, дурак, пьяница, верю-не-верю,
покер), рулетка на 2–4 игрока, дуэли 1 на 1, таблицы лидеров и бот ParrotAI в отдельном чате.
Собирается в портативное приложение для Windows (Electron), AppImage для Linux (Electron) и APK для Android (Capacitor).

**Вход в аккаунт обязателен.** Прогресс хранится только в облаке и подтягивается при входе
на любом устройстве; сессия помнится неделю. После выхода из аккаунта на устройстве
не остаётся ничего — без входа играть нельзя.

## Играть в браузере — постоянная ссылка

**https://arbyzikowo.github.io/vitalyaclicker/** — сайтовая версия на GitHub Pages.

Ссылка не меняется: файлы отдаются из ветки `main`, обновляются вместе с выпуском,
туннель для этого не нужен. Адрес онлайн-сервера клиент находит сам в `server.txt`
репозитория, поэтому перезапуск туннеля ссылку не ломает (обновления браузеру
не предлагаются — ему всегда отдаются свежие файлы).

## Что перенесено из второй версии игры

Игра собрана из двух версий: карточные столы, дуэли и рулетка остались свои,
а из второй версии взято лучшее:

- **ParrotAI** — обучаемый бот с отдельным чатом у каждого игрока (модель `server/models/Parrot-ai.bin`).
  В общем чате бот не появляется: он в списке чатов рядом с друзьями. Включение и настройка:
  «Онлайн» → «Админ» → «🦜 ParrotAI». Обучить заново можно
  через `tools/parrot-trainer.html` (служебная страница, в сборку не попадает);
- **таблицы лидеров** — шесть штук: монеты, опыт, клики, сад, победы, сообщения;
- **работы** — четыре подработки в разделе «Ещё»: 🎯 киллер, 🚚 дальнобойщик,
  📝 викторина, 🤡 найди лоха. Прогресс уровней хранится в `localStorage`;
- **цены с сервера** — каталог `configs/prices.json` (в репозиторий не входит),
  правка в админке, новые цены применяются у всех игроков сразу;
- **звуки** — выстрел и мелодии выигрыша/проигрыша в казино, аркаде и рулетке.

Формат сохранения `data.bin` (версия 24) и порядок корзин не менялись,
поэтому старые сохранения и облако работают как раньше.

## Кредиты и карточные столы

- **Досрочное погашение кредита** — в разделе «Ещё» у каждого кредита есть кнопка
  «💸 Погасить досрочно»: платятся только проценты за фактически прошедшее время,
  переплаты за оставшиеся часы нет. Долг и срок обновляются каждую секунду.
- **Выход из карточной партии = сдача.** Кнопка «🚪 Выйти» во время раунда сразу
  завершает раунд: вышедший теряет ставку, остальные получают свою ставку обратно
  и его ставку поровну. Убежать из проигрышной раздачи нельзя.

## Версия на Godot

В папке `godot/` — перенос игры на Godot 4. **Этап 4 готов:** та же игра, что на
веб-версии, плюс аккаунт, облако, чат, друзья, ParrotAI, переводы и онлайн-игры.
Клик, все апгрейды, 19 скинов с фото и крафтом, казино, крипта, майнинг, кредиты с
досрочным погашением, новости, достижения, автосохранение и оффлайн-доход; вход и
регистрация, сессия на 7 дней, облачные сейвы в настоящем формате `data.bin`
(совместимы с веб-версией — проверено на живом сохранении из облака, байт-в-байт),
автосинк каждые 10 секунд и разрешение конфликтов. Интерфейс перерисован: живой фон
со свечениями и монетками, карточки с тенями, золотые акценты, анимации клика и
барабанов казино; вёрстка тянется за окном (база 480×800, колонка до 720 px),
колесо мыши прокручивает страницу над любыми карточками и полями.

Девять вкладок сеткой 3×3: «Клик», «Апгрейды», «Скины», «Казино», «Крипта»,
«Чат», «Друзья», «Игры», «Ещё». В чате — комнаты, личные сообщения друзьям и
отдельный чат с ParrotAI (в общем чате бота нет), непрочитанные считаются. Во
вкладке «Друзья» — заявки, список, удаление и блок переводов: комиссия 5% сверху,
минимум 1000, суммы `5K`/`2.5M`/`1B`/`3T`, история операций. Входящий перевод
применяется к балансу ровно один раз и подтверждается серверу (`ack`) в том же
`save.put`, чтобы облако и `data.bin` не расходились.

Вкладка «Игры»: дуэли 1 на 1 (монетка и кости, ставка, ничья), рулетка на 2–4
игрока (числа, цвета, дюжины, колонки, чёт/нечет, фишки и «Готово») и столы с
картами — блэкджек, дурак, пьяница, верю-не-верю и покер. Создатель задаёт ставку,
число игроков и таймер хода; выход из идущей партии = сдача, ставка уходит
остальным. Деньги списывает и выплачивает сервер, выплаты приходят в кошелёк.

Проверка: `--headless --script res://tests/selftest.gd` (131 проверка, 0 провалов),
живые `tests/cloud_test.gd` (34 проверки), `tests/social_test.gd` (16 проверок:
чат, ParrotAI, друзья, заявки, перевод и кошелёк) и `tests/play_test.gd` (60
проверок: дуэль, рулетка, блэкджек и ходы во всех карточных играх).

Для входа нужен запущенный сервер игры; адрес по умолчанию —
`http://127.0.0.1:3000` (меняется на экране входа). Локальный кэш сохранения
остался только как страховка и стирается при выходе. Сад — следующий этап.
Сервер, `data.bin` и `SAVE_VERSION 24` не меняются.
Подробности и план — `godot/README.md`.

## Запуск сервера

Самый простой способ — двойной клик по **`start-server.cmd`** (Windows) или
**`./start-server.sh`** (Linux): скрипт сам проверит Node.js 18+, поставит зависимости
при первом запуске, поднимет сервер на `http://localhost:3000` и откроет браузер.
Порт можно передать аргументом: `start-server.cmd 3001`.

Вручную:

```bash
cd server
npm install
npm start          # http://localhost:3000 — игра раздаётся этим же сервером
```

Откройте `http://localhost:3000` → появится экран входа (он же регистрация).
Проверка сервера: `npm test` (313 сквозных тестов).

Сервер одинаково работает на Windows и Linux (Node.js 18+). На Linux запуск:

```bash
cd server
npm install
node server.js            # или: ./run-server.sh — с туннелем и публикацией адреса
```

Чтобы игра была доступна из интернета, есть скрипты с туннелем cloudflared:
`tools\run-server.cmd` (Windows) и `tools/run-server.sh` (Linux) — они поднимают сервер, туннель и
публикуют адрес в `server.txt`, откуда его берут клиенты.

Чтобы сайтовая версия всегда была свежей, скрипты запуска сервера поднимают
**`tools/auto-update.sh`** — он сам подтягивает новые коммиты из GitHub и перезапускает
сервер, когда менялся серверный код (отключить: `NOUPDATE=1` или ключ `-NoUpdate`;
подробности: **README_BUILD.md**, раздел «Автообновление сервера»).

## Сборка и выпуск обновлений

```powershell
node tools\release.js --version 1.0.7                  # собрать EXE+APK и выложить релиз в GitHub
node tools\release.js --no-upload --version 1.0.7      # только собрать (файлы появятся в dist\)
node tools\release.js --upload-only --version 1.0.7    # выложить уже собранное
```

Linux-сборка (AppImage) делается на Linux — Electron не умеет собирать Linux-бинарник
на Windows. На Linux-машине с зависимостями Electron (`cd _build/electron && npm install`):

```bash
node tools/release.js --linux --version 1.0.7    # соберёт VitalyaClicker.AppImage
```

Имя файла фиксировано — `VitalyaClicker.AppImage`: по нему клиенты Linux находят
обновление в последнем релизе (так же, как EXE и APK). В релиз попадают только те
файлы, которые собрала эта машина; в `version.json` пишутся только реально
выложенные — чтобы игрок другой платформы не получил ссылку на несуществующий файл.
Игра на Linux получает обновление так же, как на Android: открывается загрузка
AppImage, после скачивания нужен `chmod +x VitalyaClicker.AppImage`.
Догрузить AppImage в уже выпущенный релиз (не удаляя EXE/APK) можно с той же версией:
`node tools/release.js --linux --upload-only --version 1.1.0`.

Из игры то же самое доступно владельцу: «Онлайн» → «Админ» → **🚀 Выпуск обновления**.
Там же выбирается, где собирать — на машине сервера или в облаке GitHub Actions (`.github/workflows/release.yml`).

Подробности сборки: [README_BUILD.md](README_BUILD.md) · документация онлайн-режима: [README_ONLINE.md](README_ONLINE.md) ·
как игра обновляется: [README_UPDATE.md](README_UPDATE.md).

## Секретов в репозитории нет

В `.gitignore` убраны: токены GitHub (`tools/gh.config.json`), промокод админки и токен сервера
(`server/secret.json`), пароль ключа подписи APK (`tools/build.config.json`), сам ключ (`*.keystore`),
данные игроков (`server/data/`). Шаблоны конфигов лежат рядом: `server/secret.example.json`,
`tools/build.config.example.json`. Для облачной сборки значение ключа подписи передаётся через секреты
репозитория (`ANDROID_KEYSTORE_B64`, `ANDROID_KS_PASS`, `ANDROID_KS_ALIAS`).
